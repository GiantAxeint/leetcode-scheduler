# 浏览器扩展 · 安装与行为说明

## 一、安装（Edge，约 1 分钟）

1. 地址栏输入 `edge://extensions/` 回车
2. 左下角打开 **开发人员模式**
3. 点 **加载解压缩的扩展**
4. 选这个文件夹：`F:\WB-box\刷题调度\extension`
   （源码在 `leetcode-coach\extension`，两处是同一份，删了重装也行）
5. 打开任意题目页，右下角会出现「刷题调度」小卡

Chrome 同理，地址换成 `chrome://extensions/`。

## 二、它会做什么

打开 `https://leetcode.cn/problems/<任意题>/` 后，右下角悬浮卡自动抓：

- 题号（从页面标题的正则里取）
- 题名
- 难度（读 `text-difficulty-*` 这个 class）
- 标签（前 4 个 `/tag/` 链接）
- 是否已通过（页面有没有绿色的提交结果标记）

你在卡上选好「排进哪一班」和「挂到哪张卡」，点**录用**，就写进本地库。

## 三、主程序没开的时候

**数据不会丢，但落盘会延后。**

原因：数据最终要进 SQLite，而 SQLite 文件只有本地服务能写；浏览器扩展没有写本地文件的权限。所以：

| 情况 | 行为 |
|---|---|
| 主程序开着 | 点录用 → 立刻写库 → 悬浮卡显示「已录用」 |
| 主程序没开 | 点录用 → 存进扩展本地队列 → 显示「已存下，开起来会自动补写」 |
| 主程序后来开了 | 每分钟检查一次，一旦探测到服务就自动补写，扩展图标上的数字清零 |

扩展图标上的橙色数字 = 还没写进去的条数。

## 四、让它基本上永远在线

主程序支持 `--silent` 参数：启动服务但**不弹浏览器**。

开机自启（可选，一条命令）：

```bat
python tools\make_shortcut.py "F:\WB-box\刷题调度\刷题调度.exe" "F:\WB-box\刷题调度" ^
  "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\刷题调度.lnk" --silent --min
```

这会在启动文件夹放一个最小化运行的快捷方式，开机后服务就在，扩展基本不会遇到离线。

不想要就删掉那个 `.lnk`。

## 五、排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 悬浮卡不出现 | 不是题目页，或页面还没加载完 | 刷新一次；确认 URL 形如 `/problems/xxx/` |
| 一直显示「未连接」 | 主程序没开，或端口被占后顺延 | 先开主程序；扩展会自动扫 8765–8785 |
| 显示「已录用」但库里没有 | 端口探测到了别的服务 | 关掉占用 8765 的程序，或重启主程序 |
| 题目信息抓错 | LeetCode 改版了 | 改 `content.js` 里的 `grab()`，DOM 选择器集中在那一处 |
