# 浏览器扩展 · 安装与行为说明

## 一、安装（Edge，约 1 分钟）

1. 地址栏输入 `edge://extensions/` 回车
2. 左下角打开 **开发人员模式**
3. 点 **加载解压缩的扩展**
4. 选这个文件夹：`F:\WB-box\刷题调度\extension`
   （源码在 `leetcode-coach\extension`，两处是同一份，删了重装也行）
5. 打开任意题目页，右下角会出现「刷题调度」小卡

Chrome 同理，地址换成 `chrome://extensions/`。

## 二、它会做什么

打开 `https://leetcode.cn/problems/<任意题>/` 后，右下角悬浮卡自动抓：

- 题号（从页面标题的正则里取）
- 题名
- 难度（读 `text-difficulty-*` 这个 class）
- 标签（前 4 个 `/tag/` 链接）
- 是否已通过（页面有没有绿色的提交结果标记）

你在卡上选好「排进哪一班」和「挂到哪张卡」，点**录用**，就写进本地库。

## 三、点「录用」之后

卡片上不会再常驻显示"已连接/未连接"，只在点下去那一刻弹一条 2 秒的提示：

| 结果 | 提示 |
|---|---|
| 写进去了 | 绿底「录用成功」 |
| 这题已经在库里 | 红底「录用失败，此题已录用」 |
| 在途名额满了 | 红底「录用失败，在途已满（15/15）」 |
| 主程序没开 | 橙底「已暂存，主程序启动后自动写入」 |

主程序没开时数据不会丢：存进扩展本地队列，每分钟探测一次，服务一上线自动补写，扩展图标上的橙色数字清零。**但落盘一定发生在主程序启动之后**——SQLite 文件只有本地服务进程能写，浏览器扩展没有写本地文件的权限。

## 四、让它基本上永远在线

主程序现在是一个**桌面窗口 + 托盘常驻**的程序，不再是挂着的黑窗：

- 点窗口右上角 **X** → 只是缩到托盘，服务继续跑，扩展随时能录用
- 想彻底退出 → 托盘图标右键 → **退出**（或到设置页把「关闭窗口时」改成直接退出）
- **开机自启** → 设置页最下面的「桌面程序」面板里勾上，或者托盘右键点「开机自启」

### 程序没开时会自动拉起

点「录用」的时候如果主程序没启动，扩展会通过自定义协议 `scj://` 把它叫起来
（启动时自动进托盘，不弹窗），然后重试写入。冷启动实测约 2 秒。

**第一次会弹一次确认**：Edge 问「要打开 刷题调度 吗？」→ 勾上 **始终允许** → 点打开。
之后不会再问。

如果没弹确认框、点了也没反应，说明协议没注册上，在主程序里随便打开一次窗口即可
（每次启动都会重写注册表），或者直接托盘右键打开程序。

旧的 `tools\install_autostart.py` 仍然可用（它写启动文件夹快捷方式），但和托盘菜单里的
开关是**同一个功能的两种装法**：用托盘开关关掉自启时，会连旧的 `.lnk` 一起清掉。

## 五、排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 悬浮卡不出现 | 不是题目页，或页面还没加载完 | 刷新一次；确认 URL 形如 `/problems/xxx/` |
| 一直显示「未连接」 | 主程序没开，或端口被占后顺延 | 先开主程序；扩展会自动扫 8765–8785 |
| 点录用后弹「要打开 刷题调度 吗」 | 第一次用 `scj://` 协议 | 勾「始终允许」再点打开，以后不再问 |
| 提示「已自动启动主程序并录用」但没窗口 | 正常：协议启动只进托盘 | 双击托盘图标看主界面 |
| 显示「已录用」但库里没有 | 端口探测到了别的服务 | 关掉占用 8765 的程序，或重启主程序 |
| 题目信息抓错 | LeetCode 改版了 | 改 `content.js` 里的 `grab()`，DOM 选择器集中在那一处 |
