## 1. 本窗口做了什么

按时间顺序，一共四段。

### 第一段：网页版 → 桌面程序（v3–v6）

| 改动 | 结果 |
|---|---|
| `console=True` → pywebview 原生窗口 + pystray 托盘 | 关窗不再挂着一个 cmd |
| 冷启动并发探测 | 9.7s → 1.9s |
| 环回请求绕开系统代理 | 修掉 502 |
| 注册 `scj://` 协议 | 能从浏览器/扩展直接唤起 |

**这一段最值钱的不是功能，是「关掉黑窗」**。用户的原话是"关掉 cmd 还在后台跑，
像个幽灵"。桌面程序的边界感就建立在这上面：进程活着，但看不见。

### 第二段：判定与撤回（v7–v10）

- 一天只判一次（`last_reviewed_at` 拦截）
- 撤回按钮：**做了三遍才做对**
  1. 第一版只还原 `stage` → 日期错了
  2. 第二版用 schema v8 的 `review_log` 快照精确还原
  3. 第三版补上 `skip` 和手动标记的撤回

### 第三段：题库抽屉（v11–v12）

今日页底部一条常驻抽屉，四个 tab：在途 / 候补 / 待归纳 / 积压。
卡片可拖进班次，班次卡也能拖回来。

**为什么不做成弹窗**：弹窗有遮罩层，HTML5 拖放跨不过去。要能拖，清单就必须长在页面上。

### 第四段：日历、壁纸、分散（v13–v22）

| 功能 | 说明 |
|---|---|
| 每日容量统一 | `daily_capacity=6`，早/午/晚只是把总量切开，不再各自配数字 |
| 间隔抖动 | `interval_fuzz=0.2`，把同档位的题散到相邻几天 |
| 日历 | 月视图、题量三色（绿/褐/红）、悬停出题目清单 |
| 分散 | 点日期勾选题目 → 选目标日（可多选）→ 二次确认 → 可撤回 |
| 壁纸 | 本地图片/视频 + Wallpaper Engine（video/picture 能播，scene/web 不能） |
| 动效 | 弹窗 pop-in 0.3s（过冲 1.28）、卡片 0.32s（1.22），只在切页播 |

**前提是静态资源已经禁了缓存**（见坑 1）。

## 3. 关键参数

| 键 | 默认 | 含义 |
|---|---|---|
| `interval_days` | `1,3,7,15,30` | 档位基数 |
| `lapse_factor` | `0.5` | 答错时下次间隔打几折 |

## 4. 八个坑（接手必读，都是真踩过的）

### 坑 1：WebView2 缓存会让前端改动「不生效」

Flask 的静态文件默认只带 `Last-Modified`，WebView2 按启发式缓存。
**改完前端、重新打包、重启，界面还是老的**。我在这上面浪费了一整轮，
还以为是自己代码写错了。

已经修了（`.js/.css/.html` 全加 `Cache-Control: no-store`），但如果你改动后端路由
或者换了资源路径，记得确认响应头。

### 坑 2：打包必须显式 `--noconsole`

命令行 `pyinstaller --onedir` 默认是 **CONSOLE 子系统**，双击就挂黑窗。
丙窗口就是栽在这上面（它的交接文档里那条命令是错的，我已经改了）。

验产物：

```python
import struct
with open(r'...刷题调度.exe','rb') as f: d = f.read(1024)
pe = struct.unpack('<I', d[0x3c:0x40])[0]
sub = struct.unpack('<H', d[pe+0x5c:pe+0x5e])[0]
print({2: 'GUI', 3: 'CONSOLE'}[sub])   # 必须是 GUI
```

### 坑 3：沙箱会拦「覆盖已存在文件」

PyInstaller 在 `os.remove` 旧产物时会被拦。解法：`--workpath` / `--distpath`
指全新的空目录，全程不碰已存在文件。

### 坑 4：端口会漂

`8765` 有时在 TIME_WAIT，程序会退到 `8766`。扩展扫 `8765–8785` 能覆盖，
但你自己写脚本对接时别硬编码 8765。

### 坑 5：LeetCode 的 `h1` 可能是「思路」面板

抓标题不能只看 DOM。1052 那条一度存成「思路」两个字。
现在优先解析 `document.title`（格式固定：`1052. 爱生气的书店老板 - 力扣（LeetCode）`）。

### 坑 6：`PICK` / `drawPick` 重名

前端全局作用域，归题型的挑选和分散选日期如果同名，后者会静默覆盖前者，
表现是「点了弹窗没反应」。我加分散时踩过一次，改叫 `SPREAD_PICK` / `drawSpreadPick`。

### 坑 7：Flask test_client 里同时开 sqlite 连接会锁库

测试脚本里一边用 `sqlite3.connect` 改数据、一边调 API，写事务没提交会
`database is locked`，API 返回 500，报错信息还很难懂。
先跑完 API 调用，再统一 `con.execute(...)` 改。

### 坑 8：判定后重绘会让卡片动画全抖一遍

卡片 animation 如果无条件挂着，每次 `loadToday()` 重绘整列都在弹。
我加了 `.view.fresh` 只在切页时挂、700ms 后摘掉。

## 5. 怎么打包、怎么验证

```bash
cd C:\Users\28903\WorkBuddy\个人项目\leetcode-coach

# 测试
.venv\Scripts\python -m pytest -q        # 应 29 passed

# 打包（显式无控制台）
.venv\Scripts\python -m PyInstaller --noconfirm --onedir --name "刷题调度" ^
  --noconsole --icon "assets/icon.ico" ^
  --add-data "app/web;app/web" --add-data "app/schema.sql;app" --add-data "assets;assets" ^
  --hidden-import webview.platforms.winforms --hidden-import webview.platforms.edgechromium ^
  --hidden-import clr_loader --hidden-import pythonnet --hidden-import pystray._win32 ^
  --workpath build_vNN --distpath dist_vNN run.py
```

部署：杀进程 → `mv _internal _internal.bak-vNN` → `cp -r dist_vNN/刷题调度/_internal .` → `cp exe`。

**注意别覆盖 `extension/` 目录**，它不在打包产物里，是单独放的。

前端小改可以不重新打包，直接 `cp app/web/*.js _internal/app/web/`，重启即可。

## 7. 给接手窗口的话

1. **先读 `docs/进度快照.md` 和这份**，再读代码。代码 7000 行，但真正复杂的只有
   `scheduler.py` 的档位推进和分散，其余都是 CRUD。

2. **改前端前先确认缓存已禁**。不然你会像我一样，改了三遍以为没生效。

3. **打包只用 `--noconsole` 那条命令**，别信任何"简化版"的 pyinstaller 调用。

4. **用户的验收方式是截图**。他会截一张界面图，圈出某个地方说"这里不对"。
   先看清他圈的是哪个元素，再动手。我至少有两次是理解偏了返工的。

5. **别再加功能了**。现在有 6 个 tab、一套隐藏的拖拽逻辑、一个壁纸系统，
   功能密度已经超过"每天用一次"这个场景需要的量。再加就是给维护上难度。

6. 用户允许你大胆做，但**数据要备份**。动库之前先 `cp` 一份到 `backup/`。

这个窗口从「要不要做成桌面程序」开始，到 v22 结束。一共 56 次提交，其中四十多次是这窗口做的。

有几件事我得说清楚：

**返工是我造成的。** 撤回做了三遍，抽屉修了两轮，缓存问题拖了一整天。
根子在于我急着给你看效果，验证只验了"源码对不对"，没验"你机器上跑的是不是那份"。
后面我学乖了，每次改完都开一个真实窗口读 DOM 状态回来，才敢说"好了"。

**你提需求的密度很高，而且方向对。** 「题目没写会怎样」「能不能撤回」
「周末能不能不跳过」——这些都是用起来才会发现的问题，说明你真的在用。
比起一开始就画大饼的功能清单，这种一条一条抠出来的东西更结实。

**最后一句劝：功能够了，去用。**
题库里 11 道题，日历上只有 9 号和 16 号有安排。这个程序的价值不在它有多少个 tab，
在于你有没有每天打开它、把那几道题做完。你已经有壁纸、有动效、有分散、
有日历了——接下来该轮到"每天刷两题"这件事本身。

真要用得不顺手，你还会回来找下一个窗口的。到时候把这份文档丢给它就行。
