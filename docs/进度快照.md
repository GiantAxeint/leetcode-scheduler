## 已完成

- 三阶段复习（自己写 → 对答案 → 判定）、档位 1/3/7/15/30 天
- 每日容量 6 题（新题 2 + 到期 4，均分早/午/晚），超出进积压
- 间隔抖动 ±20%，答对答错都加，1 天档豁免
- 题库抽屉：在途/候补/待归纳/积压，可拖进班次，班次卡可拖回移出
- 日历：月视图、题量三色、点日期勾选题目分散、右键撤回分散、目标日可多选
- 撤回判定（精确还原 next_due/solved，覆盖 skip 与手动标记）
- 壁纸：本地图片/视频 + Wallpaper Engine（video/picture 可播，scene/web 不支持）
- 动效：弹窗 pop-in 0.3s(1.28)、卡片 card-in 0.32s(1.22)，只在切页播
- 浏览器扩展抓题（标题优先 document.title，带 UI 标签黑名单）
